# 업무관리 앱

공공기관 담당자가 혼자 쓰려고 만든 **개인 업무 관리 웹 앱**입니다.
업무추진비 집행내역, 회의·행사 일정, 메모, 지급결의·특근매식비 엑셀 정리, PDF 편집을 브라우저 한 화면에서 처리합니다.

- **설치가 필요 없습니다.** HTML 파일 하나에 화면·기능·라이브러리가 모두 들어 있습니다.
- **자료는 내 PC에만 저장됩니다.** 서버나 데이터베이스가 없고, 입력한 내용은 내가 고른 PC 폴더(또는 브라우저)에만 저장됩니다. 웹 주소로 열어도 자료가 인터넷으로 나가지 않습니다.
- Chrome 또는 Edge에서 사용하세요. PC 폴더에 바로 저장하는 기능(File System Access API)이 필요합니다.

## 메뉴

| 메뉴 | 하는 일 |
|---|---|
| 홈 | 저장 폴더 연결, 보조 백업 폴더, PC 옮기기, 오늘 · 이번 주 · 다음 주 일정 |
| 일정 | 월간 · 주간 달력, 반복 일정, 끌어서 옮기기, 공휴일 · 대체공휴일 표시, 시작 전 알림 |
| 메모 | 카드형 메모, 제목 색, 파일 · 폴더 첨부, 비밀번호 잠금(AES-256 암호화) |
| 집행내역 | 예산과목별 업무추진비 집행 등록, 1인당 기준 금액 경고, 집행의뢰서 A4 인쇄, 엑셀 · CSV 저장 |
| 지급결의 | 관서운영경비 지급결의목록 엑셀 → 내역 · 사업별 합계 표, 서식 있는 엑셀 저장 |
| 특근매식비 | 초과근무 세부내역 엑셀 → 지급 기준에 따른 월별 현황표, 집계표 엑셀 저장 |
| PDF | 합치기 · 순서 바꾸기 · 회전 · 삭제 · 추출 · 나누기, 서명 · 도장 넣기 (모두 PC 안에서 처리) |
| 설정 | 저장 폴더 · 백업 · 공휴일 · 메모 잠금 · 알림 · 화면(색 테마 · 글자 크기) |

## 사용 방법

### 1. 웹에서 바로 쓰기
**https://upmu-manager-web.vercel.app** 를 Chrome 또는 Edge로 열고, 홈에서 **[저장 폴더 선택]**으로 자료를 저장할 PC 폴더를 고릅니다.
(웹에서는 PC 실행기가 없으므로 일정 알림은 앱 탭이 열려 있을 때 브라우저 알림으로 오고, 메모 첨부 열기는 쓸 수 없습니다.)


### 2. 내 PC에서 쓰기 (알림창 · 첨부 열기까지)
이 저장소를 내려받아 **`start_app.bat`**을 더블클릭하면 `http://localhost:8765`로 앱이 열립니다.
Windows에 기본으로 있는 PowerShell만 사용하며, 이 PC 안에서만 접속됩니다(127.0.0.1).

- 일정 시작 전에 화면 오른쪽 아래에 깜빡이는 알림창을 띄웁니다. 실행기가 켜져 있으면 **브라우저를 꺼도** 알림이 옵니다.
- 메모에 첨부한 파일 · 폴더를 바로 열 수 있습니다.
- 끌 때는 `stop_app.bat`.

| 파일 | 역할 |
|---|---|
| `index.html` | 앱 본체 (HTML · CSS · JS 한 파일) |
| `server.ps1` | 이 PC 전용 간이 실행기 (화면 제공, 일정 알림, 첨부 열기) |
| `popup.ps1` | 깜빡이는 일정 알림창 |
| `picker.ps1` | 메모 첨부용 파일 · 폴더 선택 창 |
| `start_app.bat` / `stop_app.bat` | 실행기 시작 / 끄기 |

## 개인정보 · 보안

- 앱은 어떤 서버로도 자료를 보내지 않습니다. 저장 폴더의 JSON 파일과 브라우저 저장소가 전부입니다.
- 잠근 메모는 비밀번호로 암호화되어 저장되며, 비밀번호는 어디에도 저장되지 않습니다(잊으면 복구 불가).
- 이 저장소에는 업무 자료가 들어 있지 않습니다. `.gitignore`가 `.env`, `*.json`(업무 자료), `backup/`을 막습니다.
